# 🚗 API Plate Recognition

A REST API for automatic vehicle license plate recognition (ANPR / ALPR) using computer vision and deep learning.

This project provides a backend service that receives vehicle images and returns the detected license plate text, making it suitable for access control systems, smart parking, fleet management, and computer vision experimentation.

---

## 🧠 Features

- License plate detection in vehicle images  
- Optical Character Recognition (OCR) for plate text extraction  
- Python-based API  
- Easy integration with external systems (web apps, mobile apps, cameras)

---

## 🛠 Tech Stack

- Python  
- OpenCV  
- Deep Learning models  
- OCR (text recognition)  
- HTML / Static assets
